# 08. 이미지 문항 제작 (얼굴·풍경)

감정 인식 영역의 **얼굴 이미지**·**풍경·추상 이미지** 유형은 아직 이미지가 없어, 같은 난이도의 글 문항이 대신 출제되고 있습니다.
이 문서의 프롬프트로 이미지를 만들어 넣으면 바로 이미지 문항으로 바뀝니다.

## 1. 필요한 이미지

| 유형 | 쉬움 | 보통 | 어려움 | 매우 어려움 | 합계 |
|---|---|---|---|---|---|
| 얼굴 (`per-face-*`) | 2 | 3 (1·2·3차 고정) | 3 (고정) | 2 | **10** |
| 풍경·추상 (`per-scene-*`) | 2 | 3 (고정) | 2 | 3 (고정) | **10** |

정답 논란이 있는 이미지를 걸러 내야 하므로 **필요한 수의 1.5~2배(30~40장)** 를 만들어 고르는 것을 권장합니다.

## 2. 만드는 순서

1. 아래 프롬프트로 생성 도구(ChatGPT 이미지, Gemini 등)에서 이미지를 만든다. 사용하는 도구의 **이용약관에서 생성 이미지의 사용 권리**를 확인한다.
2. 파일 이름을 표의 이름대로 바꿔 `assets/images/`에 넣는다 (PNG 또는 JPG, 가로 600~1000px, 1MB 이하 권장).
3. **1차 검수**: 의도한 감정과 다르게 읽히거나 두 감정으로 읽히는 이미지는 버린다. 가능하면 2~3명에게 "이 사람 감정이 뭐 같아?"라고 보기 없이 물어봐서 대부분 같은 답이 나오는 것만 쓴다.
4. 아래 '문항 틀'을 `scripts/items_per.py`에 추가하고 `python scripts/items_per.py`로 `items/per.json`을 다시 만든다.
5. `python scripts/validate_items.py --strict`와 `python -m pytest -q`로 확인한다.
6. 출시 후에는 관리자 페이지 → 문항 분석에서 '다수 응답과 정답 불일치'가 뜨는 이미지를 교체한다.

## 3. 공통 프롬프트 규칙

- **얼굴**: `photorealistic head-and-shoulders portrait of a Korean {나이·성별} person, plain light gray background, soft even studio lighting, looking at the camera, no text, no jewelry, natural skin, {표정 설명}`
  - 나이·성별을 고르게 섞는다 (20대·40대·60대 × 여성·남성).
  - 표정만 바뀌어야 하므로 배경·조명·옷은 단순하게 유지한다.
- **풍경·추상**: `{장면}, {색감·빛}, wide shot, no people, no text, painterly photograph`
  - 사람이 나오지 않게 해 '사람의 감정'이 아니라 '장면의 정서적 분위기'를 읽게 한다.

**문항 틀 (얼굴)**: 쉬움·보통은 4지선다, 어려움·매우 어려움은 '가장 맞음·가장 아님'.

```python
Q("per-face-2", "이 사람이 느끼는 감정으로 가장 알맞은 것은?",
  ["두려움", "놀람", "분노", "기쁨"], 0,
  "눈을 크게 뜨고 눈썹이 올라가면서 가운데로 모이고, 입술이 옆으로 당겨진 것은 두려움의 특징입니다. "
  "놀람은 눈썹이 올라가지만 모이지 않고 입이 동그랗게 벌어집니다.",
  "Ekman FACS: 두려움(AU1+2+4+5+20) vs 놀람(AU1+2+5+26)", image="face-2a.png"),
```

보통 단계는 **헷갈리기 쉬운 짝**(두려움↔놀람, 혐오↔분노, 슬픔↔피곤)을 보기에 함께 넣고,
어려움·매우 어려움은 **섞인 감정이나 감춘 감정**을 고르게 합니다 (예: face-4a는 ✓ "실망을 감추고 예의 있게 웃는다", ✗ "진심으로 기뻐한다").

## 6. 주의

- 생성 이미지는 실제 사진보다 표정이 과장되거나 미묘하게 어색할 수 있습니다. 보통 이상 단계는 특히 사람 검수를 거치세요.
- 한 사람(같은 얼굴)이 여러 이미지에 나오면 응시자가 얼굴이 아니라 '그 사람'을 기억하게 되므로, 이미지마다 다른 인물을 씁니다.
- 실존 인물을 닮게 만들지 않습니다.
