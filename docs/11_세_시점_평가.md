# 11. 세 시점 평가: 실무자 · 연구자 · 이용자

> 평가일 2026-10-12 · 평가 스크립트 `scripts/evaluate_perspectives.py` · 모드별 봇 4,000명 × 시나리오 3개 (총 24,000명)
> 재현: `python scripts/evaluate_perspectives.py --n 4000 --rho 0.5 --speed 8` (시나리오 B는 `--speed 12`, C는 `--speed 1000`)

> **이 평가의 개선 사항은 모두 반영했습니다. 개선 후 결과는 [12. 개선 보고서](12_개선_보고서.md)를 보세요.**

## 요약

| 시점 | 평가 | 한 줄 |
|---|---|---|
| **실무자** (검사를 만들고 운영하는 사람) | **B−** | 출제·채점 구조는 탄탄하나, **위기 대처 제한시간이 읽기 속도를 재고 있고** 문항 판정에 응시자 90~160명이 필요하다 |
| **연구자** (측정이 맞는지 따지는 사람) | **C+** | 종합 EQ 신뢰도는 높지만(0.90~0.97), **규준이 '모든 영역 능력이 같다'는 가정 위에 있어 EQ 분포가 좁아지고**, 정답·모수·규준 모두 실제 데이터 없이 가정이다 |
| **이용자** (이런 검사를 좋아하는 사람) | **B** | 다시 해도 점수가 비슷하고 강점 표시는 대부분 맞지만, **유형의 56~73%가 '균형형·상황맞춤형'** 이라 유형을 기대한 사람에겐 심심하다 |

**종합: 구조와 검증 장치는 출시 가능한 수준이지만, 출시 전에 고쳐야 할 것이 두 가지 있습니다.**
1. 위기 대처의 시간 압박이 판단보다 읽기 속도를 잽니다 (읽기 느린 1/4은 문항 61~64%를 시간 초과).
2. 시뮬레이션 규준이 영역 능력이 모두 같다고 가정해, 영역 능력이 서로 다른 실제 사람에게는 EQ 표준편차가 15가 아니라 약 10으로 나옵니다 (130 이상이 2.3%가 아니라 0.1~0.5%).

평가 등급은 아래 수치를 바탕으로 한 저(Claude)의 판단입니다.

## 1. 평가 방법

### 이번 봇이 지금까지와 다른 점
지금까지의 검증 봇은 **모든 영역 능력이 같은 사람**이었습니다. 이번에는 실제 사람처럼
- **영역마다 능력이 다름**: 영역 능력 = √0.5 × 일반 능력 + √0.5 × 영역 고유 능력 (영역끼리 상관 0.5. 실제 값은 모르며, 정서지능 하위 영역이 '관련은 있지만 같지 않다'는 정도를 나타낸 가정)
- **읽기 속도와 생각 시간이 사람마다 다름**: 응답 시간 = (문제 + 보기 글자 수) ÷ 읽기 속도 + 생각 시간(중앙값 4초, 어려울수록 길게). 위기 대처는 제한시간을 넘으면 미응답
- **성향도 연속적**: 세 축 성향 × 강도 0~2 (고르게)

봇 한 명이 실제 출제 로직으로 겹치지 않는 1·2·3차를 풉니다.

| 시나리오 | 영역 능력 상관 | 읽기 속도 중앙값 | 목적 |
|---|---|---|---|
| **A (기본)** | 0.5 | 초당 8자 | 보통 사람 가정 |
| B | 0.5 | 초당 12자 | 빨리 읽는 사람이 많을 때 |
| C | 0.5 | 시간 제한 없음 | 시간 압박을 뺀 순수 측정 |

### 평가 도구 자체의 검증
영역 능력이 모두 같고(상관 1) 시간 제한이 없으면 규준을 만든 봇과 조건이 같으므로 EQ 평균 100·표준편차 15가 나와야 합니다.
처음에는 평균 105.7·표준편차 12가 나와 평가 스크립트의 버그 두 개(놓친 문항에서 우연히 정답·정답 최악을 고르는 경우)를 찾아 고쳤고,
고친 뒤 **평균 100.1 · 표준편차 14.8~14.9**로 규준과 일치했습니다. 규준을 만든 스크립트의 봇으로 같은 계산을 하면 100.2 · 14.5~15.1입니다.

## 2. 실무자 시점: 만들고 운영할 수 있나

| 항목 | 빠른 검사 | 정밀 검사 | 판단 |
|---|---|---|---|
| 1차 문제 풀이 시간 (A) 중앙값 · 90% | 13.6분 · 18.3분 | 27.4분 · 36.8분 | 자기평가·마지막 질문 약 5분을 더하면 안내(20분·40분)와 맞음 |
| **위기 대처 시간 초과 (A)** 문항 평균 | **19.4%** | **23.7%** | ✗ 너무 많음 |
| 위기 대처를 1개 이상 시간 초과한 사람 (A) | 35% | 57% | ✗ |
| 읽기 느린 1/4의 위기 대처 시간 초과 (A) | **60.8%** | **64.2%** | ✗ |
| 위기 대처 시간 초과 (B, 빨리 읽는 사람들) | 3.0% | 4.2% | △ |
| 1차 문항 노출률 중앙값 · 최대 | 33% · 35% | 33% · 51% | △ 공개 검사라면 정답 공유 위험 (슬롯당 3문항) |
| 1~3차에 한 번도 안 쓰이는 문항 (심층검사 전용) | 211개 | 122개 | 정상 (설계상 심층검사용) |
| 문항 판정(응답 30개)에 필요한 1차 응시자 | 중앙값 90명 · 최대 156명 | 중앙값 90명 · 최대 161명 | 심층검사 전용 문항은 훨씬 더 많이 필요 |
| 1차 만점 / 전부 틀림 EQ | 137 / 59 | 140 / 57 | 1차만으로는 140 위를 보여 줄 수 없음 |

**왜 위기 대처가 문제인가**: 위기 대처 문항은 문제와 보기를 합쳐 중앙값 127~154자인데 제한시간은 25초(쉬움·보통)·35초(어려움 이상)입니다.
생각 시간 없이 읽기만 해도 초당 4.2~5.6자가 필요합니다. 초당 8자로 읽는 사람이 생각 시간 4초를 쓰면 보통 단계(140자, 25초)는 빠듯합니다.
실제로 문항당 시간 초과율은 **25초를 주는 쉬움·보통 단계가 가장 높습니다** (정밀 A: 쉬움 22% · 보통 38% · 어려움 12% · 매우 어려움 17%, 빠른 A: 22% · 25% · 15% · 16%).

그 밖에 문항을 보고 확인한 것:
- 정답 유형이 한쪽에 몰린 영역 (관계 갈등 대화형 22 · 경계형 4, 대인관계 솔직형 16 · 존중형 4, 감정 활용 몰입형 2) → 유형 판정 기회가 줄어듦 ([09](09_유형_판정.md))
- 감정 인식 이미지 20장이 없어 8개 슬롯을 글 문항으로 대신 출제 중
- 관리자 분석·응답 신뢰도·문항 판정 화면은 갖춰져 있음 (운영 도구는 충분)

## 3. 연구자 시점: 재는 것을 제대로 재나

| 항목 | 빠른 1차 | 정밀 1차 | 1~3차 합산 | 판단 |
|---|---|---|---|---|
| 종합 EQ ↔ 참 평균 능력 | 0.90 | 0.94 | 0.95 ~ 0.97 | ✓ |
| 종합 EQ 재검사 (1차 ↔ 2차, 다른 문항) | 0.83 | 0.90 | — | ✓ |
| 영역 점수 ↔ 그 영역 참 능력 (위기 대처 제외) | 0.72 ~ 0.74 | 0.82 ~ 0.84 | 0.87 ~ 0.93 | ✓ |
| 영역 점수 ↔ 다른 영역 참 능력 | 0.36 ~ 0.37 | 0.41 ~ 0.43 | — | ✓ 수렴과 차이 약 0.4 |
| **위기 대처 영역 점수 ↔ 참 능력 (A)** | **0.56** | **0.61** | 0.64 ~ 0.67 | ✗ 시간 제한이 없으면 0.73 / 0.83 |
| **위기 대처 점수와 읽기 속도의 편상관 (A, 능력 통제)** | **0.48** | **0.59** | — | ✗ 다른 영역은 0.00 ~ 0.03 |
| 개인 프로필(영역 간 차이) 회복 | 0.57 | 0.68 | 0.73 ~ 0.79 | △ 영역 차이의 신뢰도 0.33(빠른) · 0.46(정밀) |
| 영역 점수 재검사 | 0.53 ~ 0.63 | 0.71 ~ 0.75 | — | △ |
| 최선·최악에서 최선만 맞혀 0점 | 19.3% | 18.9% | — | △ 부분 점수 정보가 버려짐 |
| **EQ 분포 (A)** 표준편차 · 130 이상 | **10.5 · 0.4%** | **10.0 · 0.1%** | — | ✗ 기대 15 · 2.3% |
| EQ 분포 (C, 시간 제한 없음) | 10.8 · 0.5% | 10.2 · 0.1% | — | ✗ 시간 문제와 별개 |

**EQ 분포가 좁아지는 이유**: 시뮬레이션 규준은 "모든 영역 능력이 같은 봇"의 점수 분포로 만들었습니다.
영역 능력이 서로 다르면 8개 영역의 평균 능력은 그보다 덜 퍼지고(상관 0.5일 때 표준편차 약 0.75배),
규준표는 그것을 모른 채 같은 기준으로 바꾸므로 EQ가 100 쪽으로 몰립니다. 실제 첫 응시자가 100명을 넘으면
실제 분포 기준으로 바뀌므로 그 뒤에는 저절로 풀리는 문제이지만, **출시 초기 응시자는 실제보다 평범한 위치를 받습니다.**

시뮬레이션으로는 확인할 수 없는 연구상의 한계:
- **정답 키**는 이론을 바탕으로 한 사람(Claude)이 정했습니다. 전문가 패널 합의나 사전 조사가 없습니다.
- **문항 모수**(난이도·변별도)가 가정값입니다. 3PL 보정에는 문항당 수백 명이 필요합니다.
- **종합 점수는 하나의 능력으로 추정**하지만 영역은 서로 다른 능력이라고 설명합니다. 실제 응답으로 요인 구조를 확인해야 합니다.
- **유형**은 '단서를 놓쳤을 때 기우는 방향'이라는 새 구성 개념이라 선행 연구가 없습니다.
- **외적 타당도**(다른 EQ 검사, 대인 관계 결과와의 관계)와 **집단 간 공정성**(나이·성별에 따라 문항이 다르게 작동하는지)은 아직 측정하지 않았습니다.

## 4. 이용자 시점: 해 볼 만하고 믿을 만한가

| 항목 | 빠른 | 정밀 | 판단 |
|---|---|---|---|
| 다시 풀었을 때 EQ 차이 중앙값 · 90% | 4.1점 · 10.2점 | 2.8점 · 7.2점 | ✓ |
| 다시 풀었을 때 15점 이상 차이 | 1.5% | 0.5% | ✓ |
| 수준 이름(보통·우수 등)이 바뀜 | 20% | 14% | △ 경계 근처 사람 |
| 1차 90% 범위가 2차 점수를 포함 | 80% | 80% | △ 재검사에는 오차가 두 번 들어가므로 90%보다 낮은 것이 정상 |
| 영역 점수 오차 (90% 범위 반폭) | **±23점** | ±16점 | ✗ 빠른 검사 영역 점수는 거의 참고용 |
| '상대적 강점'이 표시된 사람 | 45% | 76% | — |
| 표시된 강점이 실제로 본인 평균보다 높음 | 91% | 94% | ✓ |
| 실제 최고 영역이 강점에 포함 | 54% | 68% | △ |
| '더 키우면 좋은 영역'이 실제로 약함 | 86% | 89% | ✓ |
| **유형 이름이 균형형·상황맞춤형** | **73%** | **56%** | ✗ 유형을 기대한 사람에겐 심심함 |
| 서로 다른 유형 이름 수 | 22개 | 26개 | ✓ 다양함은 충분 |
| 다시 풀었을 때 같은 유형 이름 | 56% | 52% | △ |
| 성향이 강한 1/3이 축 이름을 받음 | 41% | 67% | △ |
| 능력 상위 1/3의 이름 | 상황맞춤형 66% | 상황맞춤형 61% | 잘하는 사람일수록 유형이 비슷해짐 |

이용자가 느낄 점:
- **좋은 점**: 다시 해도 점수가 거의 같고, 강점·약점 표시가 대부분 맞으며, 응답 신뢰도·근거 설명이 투명합니다.
- **아쉬운 점**: 정밀 검사가 30분 넘게 걸리고(가볍게 하기엔 김), 유형 이름 절반 이상이 '균형형·상황맞춤형'이라 공유할 거리가 적습니다.
  빠른 검사의 영역 점수는 오차가 ±23점이라 막대그래프를 믿기 어렵습니다. 위기 대처는 읽기 느린 사람에게 억울합니다.

## 5. 개선 사항 (우선순위)

| 순위 | 개선 | 근거 | 시점 |
|---|---|---|---|
| **1** | **위기 대처의 읽기와 판단 분리**: 상황을 먼저 시간 제한 없이(또는 넉넉히) 보여 주고, 보기가 열린 뒤부터 초시계 시작. 또는 제한시간을 40·50초로 늘리거나 문항을 100자 안팎으로 줄이기 | 시간 초과 19~24%, 읽기 속도 편상관 0.48~0.59, 수렴 0.56~0.61 (제한 없으면 0.73~0.83) | 실무·연구·이용 |
| **2** | **시뮬레이션 규준을 영역 능력이 다른 봇(상관 약 0.5)으로 다시 만들기**, 실제 규준 전환 기준을 100명보다 늘리는 것도 검토 | EQ 표준편차 약 10, 130 이상 0.1~0.5% (기대 15 · 2.3%) | 연구·이용 |
| 3 | 최선·최악에 부분 점수 (최선만 맞으면 0.5 등, 채점 모형 변경 필요) | 응답의 19%가 0점 처리되며 정보를 잃음 | 연구 |
| 4 | 빠른 검사에서는 영역 막대 대신 "강점 후보" 정도만 표시 | 영역 오차 ±23점 | 이용 |
| 5 | 유형 이름: 우연 검정을 통과하지 못한 약한 경향도 "약한 ○○ 경향"으로 보여 주기 (확신도 표시) | 균형형·상황맞춤형 56~73% | 이용 |
| 6 | 문항 검토 때 정답 유형 쏠림 바로잡기 (관계 갈등 경계형, 대인관계 존중형, 감정 활용 몰입형 늘리기) | 유형 판정 기회, 정답 패턴 학습 방지 | 실무 |
| 7 | 90% 범위가 수준 경계를 걸치면 "경계 근처"라고 안내 | 다시 하면 수준 이름이 바뀌는 비율 14~20% | 이용 |
| 8 | 출시 후 연구 과제: 전문가 정답 검토, 300명 이상 시범 조사로 문항 모수 보정, 요인 구조, 다른 검사와의 상관, 집단 간 공정성 | 시뮬레이션으로 확인할 수 없는 부분 | 연구 |

1·2번은 코드 수정과 봇 재검증으로 바로 할 수 있고, 3번은 채점 모형과 규준을 함께 바꿔야 합니다.

## 6. 이 평가의 한계

- 모든 수치는 **가정한 봇 모형** 위에서 나왔습니다. 특히 읽기 속도(초당 8자·12자)와 영역 능력 상관(0.5)은 가정입니다.
  위기 대처 문제는 읽기 속도 가정에 크게 좌우되므로(초당 8자면 시간 초과 19~24%, 12자면 3~4%), 실제 응답 시간으로 꼭 다시 확인해야 합니다.
  관리자 페이지의 문항별 응답 시간과 시간 초과 비율을 보면 됩니다.
