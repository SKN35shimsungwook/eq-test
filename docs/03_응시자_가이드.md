# 03. 응시자 가이드

## 1. 어떤 검사인가요

감정을 알아차리고, 이해하고, 활용하고, 다루는 힘을 8개 영역에서 측정해 **EQ(평균 100, 표준편차 15)** 로 알려 주는
온라인 정서 역량 테스트입니다. 이름이나 연락처는 받지 않습니다.

> 표준화된 전문 심리검사를 대체하지 않습니다. 진단·채용·진학 판단에 쓰지 마세요.

| 영역 | 측정하는 힘 | 문제 예 |
|---|---|---|
| 감정 인식 | 말투·행동·표정에서 감정을 알아차리는 힘 | "'그냥…. 묻지 마'라는 답장, 친구의 기분은?" |
| 감정 이해 | 감정이 왜 생기고 어떻게 바뀌는지 이해하는 힘 | "합격했지만 가족과 떨어져야 할 때의 마음은?" |
| 감정 활용 | 일에 맞는 기분을 만들고 감정을 행동의 힘으로 쓰는 능력 | "계약서 오탈자를 찾을 때 도움이 되는 기분은?" |
| 감정 조절 | 내 감정을 건강하게 다스리는 힘 | "단톡방의 비꼬는 말에 화가 날 때 먼저 할 일은?" |
| 대인관계·공감 | 다른 사람의 마음에 맞게 반응하는 힘 | "반려묘를 잃은 친구에게 좋은 첫마디는?" |
| 관계 갈등 | 적응·배신·소외·가족·연애 갈등을 풀어 가는 방식 | "사과는 했지만 같은 일이 세 번째일 때 알맞은 대응은?" |
| 위기 대처 | 갑작스러운 압박 속 판단 | "기름 불이 붙었을 때 가장 알맞은 행동은?" (상황은 천천히 읽고, 보기를 연 뒤 25~30초) |
| 맥락 파악 | 말 속의 숨은 뜻과 분위기를 읽는 힘 | "마감 30분 전 자료를 받고 '빨리도 보내셨네요'의 뜻은?" |

## 2. 검사 방식

| | 빠른 검사 | 정밀 검사 |
|---|---|---|
| 시간 | 약 20분 | 약 40분 |
| 문항 | 영역마다 4문항 (쉬움~매우 어려움 하나씩) | 영역마다 8문항 |
| 결과 | 종합 EQ 중심, 영역 점수는 참고용 | 영역별 강점·약점까지 |

## 3. 진행 순서

```
자기평가 (36문항, 약 4분, 1차 전에만)
  → 1차 검증 → 마지막 질문 (8문항, 약 1분, 1차 끝에만) → 결과
     [2차 검증 하기] → 1~2차 합산 결과
        [3차 검증 하기] → 1~3차 합산 결과
           [심층검사 하기] → 1~3차 + 심층검사 합산 결과
```

- **자기평가**: "평소의 나"에 얼마나 해당하는지 고릅니다. 정답이 없고 EQ에는 들어가지 않습니다.
- **1·2·3차 검증**: 같은 구성의 검사를 **앞에서 나온 문제와 겹치지 않는 새 문제**로 다시 풉니다. 합칠수록 오차가 줄어듭니다.
- **심층검사**: 3차 뒤에 열립니다. 지금까지의 결과에 맞춰 문제를 **한 문제씩** 골라 냅니다 (영역당 3~6문항).

## 4. 화면 사용법

- 영역마다 안내 화면이 먼저 나오고, **시작**을 누르면 그 영역의 제한시간이 흐릅니다.
- **4지선다** (쉬움·보통): 보기를 누르거나 키보드 1~4 / A~D.
- **최선·최악** (어려움·매우 어려움): 보기마다 **✓ 가장 맞음**과 **✗ 가장 아님** 버튼이 있습니다. 하나씩 고르며, **둘 다 맞아야 정답**이고 가장 맞는 것만 맞히면 부분 점수를 받습니다. 같은 버튼을 다시 누르면 취소됩니다.
- 1·2·3차는 **이전/다음**과 번호로 자유롭게 오갈 수 있습니다. 끝까지 고른 문항에 ✓가 붙습니다.
- **위기 대처**는 한 문제씩 풉니다. 먼저 **상황만 시간 제한 없이** 읽고 **보기 열기**를 누르면 초시계(25~30초)가 시작됩니다. 앞 문제로 돌아갈 수 없고, 시간이 끝나면 그때까지 고른 답으로 넘어갑니다. 읽는 속도가 점수에 섞이지 않게 하려는 방식입니다.
- 새로고침해도 주소의 `?s=…`로 같은 문항·같은 남은 시간에서 이어집니다.

## 5. 결과 읽는 법

| 항목 | 뜻 |
|---|---|
| **응답 신뢰도** | 응답이 일관되고 성실했는지 (높음·보통·낮음). EQ 점수는 바꾸지 않고, 낮으면 자기평가 비교와 유형을 참고로만 읽으라고 안내 |
| **EQ** | 지금까지 푼 모든 차수를 합친 점수 (평균 100, 표준편차 15) |
| **정확한 범위 (90%)** | 실제 EQ가 90% 확률로 들어 있는 범위 |
| **전체 응시자 중 위치** | 상위/하위 몇 % |
| **수준** | 130 이상 매우 우수 · 115~129 우수 · 90~114 보통 · 70~89 개발 필요 · 69 이하 집중 개선 필요 |
| **내가 보는 나 vs 실제** | 자기평가와 문제 풀이 결과를 같은 척도로 비교. 15점 넘게 차이 나면 과대·과소평가로 표시 |
| **나의 정서 유형** | 상황에 맞지 않는 보기를 골랐을 때 어느 쪽으로 기우는지. 세 축(감정↔문제, 다가감↔거리, 표현↔절제)과 조합 이름, 영역별 유형. 대부분 맞히면 '상황맞춤형' |
| **이렇게 키워 보세요** | 점수가 가장 낮은 두 영역의 연습 방법 |

- 영역 점수는 문항이 적어 오차가 큽니다. 범위를 함께 보세요. 특히 **감정 활용**은 참고용입니다. 빠른 검사 1차처럼 영역마다 4문항뿐이면 점수 대신 **강점 후보·키울 영역 후보**만 보여 드립니다.
- 점수가 수준 경계(70·90·115·130) 가까이 있으면 **경계 근처** 안내가 나옵니다. 다시 하면 수준 이름이 바뀔 수 있다는 뜻입니다.
- 유형 이름에 **확신도**가 붙습니다. '약함'(예: "표현형 경향")은 그쪽으로 기우는 기미가 보이지만 우연일 수도 있다는 뜻입니다.
- 자기평가가 실제보다 높게 나오는 것은 흔한 일입니다(연구에서 자기평가와 실제 수행의 상관은 0.2 안팎). 그 차이가 나를 이해하는 단서가 됩니다.
- **유형은 점수와 별개**입니다. 판단이 애매할 때 어떤 방식으로 기우는지를 보며, 우연으로도 생길 만한 기울기는 이름에 넣지 않습니다. 좋은 유형·나쁜 유형은 없고, 한쪽으로 크게 치우친 축은 반대쪽 상황에서 놓치기 쉬운 점을 알려 줍니다. 빠른 검사는 선택이 적어 유형이 덜 정확합니다.
- 점수 기준이 "가상 응시자 시뮬레이션 분포"로 표시되면 아직 실제 응시자가 적은 상태입니다. 첫 응시자가 300명을 넘으면 실제 분포로 바뀝니다.

## 6. 자주 묻는 질문

**Q. 정답이 왜 그건가요? 사람마다 다를 수 있잖아요.**
정답은 감정 연구의 이론(감정이 생기는 조건, 효과적인 조절 방법 등)으로 정했고, 문항마다 해설이 있습니다.
실제 응답이 쌓이면, 잘하는 응시자 대부분이 다른 답을 고르는 문항을 찾아 다시 검토합니다.

**Q. 보기가 다 괜찮아 보여요.**
일부러 그렇게 만들었습니다. 네 보기 모두 어떤 상황에서는 정답이 될 수 있고, 문제 속 **단서 하나**(상대가 원하는 것, 반복 여부, 되돌릴 수 있는지 등)가 지금 상황의 정답을 가릅니다.

**Q. 마지막 질문은 왜 하나요? 신뢰도가 '낮음'이면 점수가 깎이나요?**
누구나 있는 마음을 부정하는지, 같은 내용을 다르게 물었을 때 일관되게 답하는지를 봅니다. 문제를 너무 빨리 풀거나 한 자리만 고른 경우도 함께 봅니다. **점수는 깎이지 않으며**, 결과를 얼마나 믿고 읽을지만 알려 드립니다. 성실하게 답한 사람이 '낮음'을 받는 경우는 봇 검증에서 약 2%였습니다.

**Q. 위기 대처 시간이 너무 짧아요.**
순간 판단을 재는 영역이라 일부러 짧게 두었습니다. 상황을 다 읽기 어렵다면 핵심 위험(안전·사람)에 먼저 집중해 보세요.
