# 10. 응답 신뢰도: 마지막 질문과 봇 검증 보고서

> 검증일 2026-10-12 · 대상 `core/validity.py`, `items/final_check.json` · 검증 스크립트 `scripts/simulate_validity.py`
> 봇 모드별 21,000명 (7가지 응답 방식 × 3,000명) · 결과 재현: `python scripts/simulate_validity.py --n 21000 --workers 8`

## 요약

| 질문 | 답 |
|---|---|
| 성실하게 답한 사람을 '낮음'으로 잘못 거르나? | **1.4 ~ 2.3%** (능력과 무관하게 1.6 ~ 2.5%) |
| 아무렇게나·대충 답한 사람을 잡아내나? | **99.9 ~ 100%** '낮음' |
| 문제 풀이 중간부터 대충 한 사람은? | 47 ~ 51% '낮음', **나머지 전부 '보통'** (100% 경고) |
| 일부러 좋게 보이려 한 사람은? | 강하게 꾸미면 50% '낮음' · 84~85% 경고, 은근히 꾸미면 10% '낮음' · 39% 경고 |
| 같은 응답이면 같은 판정인가? | **100%** (응답 순서를 바꿔도) |
| EQ 점수에 영향이 있나? | **없음.** 신뢰도는 결과를 읽는 방법만 안내한다 |

**결론**: 성실하지 않은 응답(무작위·몰아 찍기)은 거의 확실하게 잡고, 성실한 사람을 잘못 거르는 일은 약 2%로 드뭅니다.
**좋게 보이려는 꾸밈은 절반 정도만 잡습니다.** 꾸밈을 잘하는 사람은 이 장치도 넘을 수 있으므로 거짓말 탐지기가 아니라 경고등입니다.

## 1. 무엇을 추가했나

### 마지막 질문 (1차 검증 끝, 8문항, 약 1분)

| 종류 | 문항 | 보는 것 |
|---|---|---|
| 욕구 부정 4 | 아무도 모른다면 규칙을 살짝 어기고 싶다는 생각이 든 적이 한 번도 없다 · 남에게 인정받고 싶어서 무언가를 한 적이 한 번도 없다 · 싫어하는 사람이 곤란해졌을 때 속으로 고소하다고 느낀 적이 한 번도 없다 · 피곤해서 남의 부탁을 모른 척하고 싶었던 적이 한 번도 없다 | 누구나 있는 욕구를 부정하는가 (좋게 보이려는 경향) |
| 다시 묻기 4 | 시작 자기평가 4문항을 **반대 방향으로** 바꿔 다시 묻기 (감정 조절·대인관계·맥락 파악·위기 대처에서 하나씩) | 같은 내용에 일관되게 답하는가 |

시작 자기평가의 점검 문항 4개("한 번도 짜증을 낸 적이 없다" 등)와 합쳐 **욕구·실수 부정 8개**를 봅니다.

### 판정 규칙 (`core/validity.py`)

| 신호 | 낮음 | 보통 |
|---|---|---|
| 욕구·실수 부정 (8개 중 '그렇다' 이상) | 6개 이상 | 4 ~ 5개 |
| 다시 묻기에서 3점 이상 어긋난 짝 (4쌍 중) | 2쌍 이상 | — |
| 자기평가·마지막 질문을 한 칸에 몰아 답함 | 80% 이상 | — |
| 문제 풀이 2.5초 안 응답 | 50% 이상 | 20% 이상 |
| 문제 풀이 같은 위치(A~D) 선택 | 60% 이상 | 50% 이상 |

- 하나라도 '낮음'이면 낮음, 아니면 '보통' 신호가 있으면 보통, 없으면 높음.
- 문제 풀이 신호는 응답이 12개 이상일 때만 봅니다. 마지막 질문을 하지 않은 예전 세션은 욕구 8개 기준을 쓰지 않습니다.
- **결과 화면**: 최종 결과 맨 위에 "응답 신뢰도: 높음/보통/낮음"과 이유. 낮음이면 자기평가 비교와 정서 유형에 '참고로만' 표시.
- **관리자 페이지**: 자기평가 탭에 판정 분포와 높음이 아닌 세션 목록.

## 2. 봇 설계

| 봇 | 자기평가·마지막 질문 | 문제 풀이 |
|---|---|---|
| 성실 | 영역 성향 + 잡음(표준편차 0.8) + 사람마다 '그렇다' 쪽 습관, 욕구 부정 확률 평균 13% | 3PL 능력대로, 문항당 중앙값 약 9초 |
| 성실·빠른 독자 | 성실과 같음 | 문항당 중앙값 약 4.5초 (거짓 경보가 가장 나기 쉬운 사람) |
| 은근한 꾸밈 | 자기평가 +0.5, 욕구 부정 확률 평균 38% | 성실 |
| 강한 꾸밈 | 자기평가 +1.0, 욕구 부정 확률 평균 67% | 성실 |
| 무작위 | 모두 아무렇게나 | 아무 보기나, 약 1.5초 |
| 대충 | 85%를 한 칸에 | 85%를 한 위치에, 약 1.2초 |
| 절반 대충 | 자기평가는 성실, 마지막 질문은 한 칸에 | 앞 절반 성실, 뒤 절반 대충 |

봇은 실제 출제 로직으로 1차 검증 검사지를 받고, 결과 화면과 같은 `vd.assess`로 판정했습니다.

## 3. 결과

### 3-1. 판정 분포

| 봇 | 빠른 검사: 높음 / 보통 / 낮음 | 정밀 검사: 높음 / 보통 / 낮음 |
|---|---|---|
| 성실 | 92.7 / 5.8 / **1.4%** | 92.9 / 4.8 / **2.3%** |
| 성실·빠른 독자 | 81.4 / 16.6 / **2.0%** | 81.6 / 16.4 / **2.0%** |
| 은근한 꾸밈 | 60.8 / 29.3 / 9.9% | 60.9 / 29.1 / 10.0% |
| 강한 꾸밈 | 15.6 / 33.7 / 50.7% | 14.8 / 34.7 / 50.4% |
| 무작위 | 0 / 0.1 / **99.9%** | 0 / 0 / **100%** |
| 대충 | 0 / 0 / **100%** | 0 / 0 / **100%** |
| 절반 대충 | 0 / 48.7 / 51.3% | 0 / 52.7 / 47.3% |

### 3-2. 성실 봇의 능력 구간별 '낮음' (능력과 무관해야 함)

| | 하 | 중 | 상 |
|---|---|---|---|
| 빠른 검사 | 1.7% | 1.7% | 1.8% |
| 정밀 검사 | 1.6% | 2.4% | 2.5% |

못 푸는 사람이 '불성실'로 몰리지 않습니다. 오답도 정답 위치처럼 고르게 흩어지기 때문입니다.

### 3-3. 신호별로 걸린 비율 (정밀 검사)

| 봇 | 욕구 부정 | 조금 | 어긋남 | 한 칸 | 너무 빠름 | 조금 빠름 | 한 위치 | 조금 |
|---|---|---|---|---|---|---|---|---|
| 성실 | 0.7 | 4.7 | 1.6 | 0 | 0 | 0.2 | 0 | 0 |
| 성실·빠른 독자 | 0.4 | 4.3 | 1.3 | 0 | 0.2 | 13.0 | 0 | 0 |
| 은근한 꾸밈 | 10.0 | 28.9 | 0 | 0 | 0 | 0.3 | 0 | 0 |
| 강한 꾸밈 | 50.4 | 34.7 | 0.2 | 0 | 0 | 0.2 | 0 | 0 |
| 무작위 | 5.4 | 36.6 | 25.0 | 0 | 100 | 0 | 0 | 0 |
| 대충 | 64.4 | 1.7 | 32.5 | 93.4 | 100 | 0 | 100 | 0 |
| 절반 대충 | 5.7 | 48.6 | 22.3 | 0 | 3.5 | 96.5 | 25.6 | 69.0 |

(단위 %. 한 봇이 여러 신호에 걸릴 수 있음)

- 성실한 사람의 '낮음' 대부분은 **다시 묻기에서 우연히 크게 어긋난 경우(1.3~1.6%)** 와 **욕구 부정이 많은 정직한 사람(0.4~0.7%)** 입니다.
- 빠른 독자는 13%가 "아주 빨리 답한 문제가 꽤 있습니다"(보통)를 받습니다. 사실이므로 '낮음'으로 올리지 않았습니다.

### 3-4. 지표 평균 (정밀 검사)

| 지표 | 성실 | 강한 꾸밈 | 무작위 | 대충 |
|---|---|---|---|---|
| 욕구·실수 부정 (0~8) | 1.06 | 5.36 | 3.25 | 4.98 |
| 어긋난 짝 (0~4) | 0.17 | 0.03 | 0.98 | 1.16 |
| 자기평가 한 칸 비율 | 0.35 | 0.38 | 0.28 | 0.88 |
| 2.5초 안 응답 비율 | 0.01 | 0.01 | 0.74 | 0.86 |
| 문제 풀이 한 위치 비율 | 0.31 | 0.31 | 0.32 | 0.89 |

꾸미는 사람은 **오히려 더 일관적**입니다(어긋난 짝 0.03). 그래서 꾸밈은 일관성이 아니라 욕구 부정으로만 잡힙니다.

## 4. 기준값을 정한 과정

| 시도 | 성실 '낮음' | 강한 꾸밈 '낮음' | 바꾼 이유 |
|---|---|---|---|
| 욕구 부정 5개↑ 낮음, 빠른 응답 40%↑ 낮음 | 3.6 ~ 4.8% | 72% | 성실한 사람 오경보가 목표(약 2%)보다 많음 |
| 욕구 부정 6개↑ 낮음 | 1.7 ~ 3.1% | 50 ~ 54% | 빠른 독자 오경보가 남음 |
| + 빠른 응답 50%↑ 낮음 **(채택)** | **1.4 ~ 2.3%** | 50% | 무작위·대충은 74~86%가 빨라 여전히 100% 탐지 |

성실한 사람을 잘못 거르는 쪽이 더 해롭다고 보고(결과를 믿지 말라는 안내를 받게 되므로), 꾸밈 탐지율을 일부 양보했습니다.

## 6. 한계와 다음 단계

- **봇은 가정한 모형입니다.** 실제 사람의 욕구 부정 비율(가정: 평균 13%)과 응답 속도가 다르면 기준을 다시 맞춰야 합니다.
  관리자 페이지의 판정 분포를 보고, 실제 '낮음'이 2%보다 크게 많으면 문항이나 기준을 검토합니다.
- **꾸밈 탐지는 절반 수준**입니다. 문항을 늘리면 오르지만 검사가 길어집니다.
- **1차에만 묻습니다.** 2·3차와 심층검사는 문제 풀이 신호(속도·위치)만 쌓입니다.
- 판정은 EQ 점수를 바꾸지 않습니다. 규준 계산에서 '낮음' 세션을 뺄지는 실제 데이터를 보고 정합니다.
