# 01. 연구 정리

EQ 테스트를 설계하기 전에 조사한 내용과, 사용자가 가져온 보고서 2개에서 반영한 것·반영하지 않은 것을 정리했습니다.
보고서 정리본은 [research/원본](research/원본/)에 있습니다.

## 1. 정서지능(EQ)을 재는 세 가지 방식

| 모델 | 정의 | 측정 방식 | 대표 검사 |
|---|---|---|---|
| **능력 모델** (Mayer·Salovey·Caruso) | 감정을 지각·이해·활용·관리하는 인지 능력 | 정답이 있는 과제 (최대 수행 검사) | MSCEIT (141문항), GECo (110문항), STEU·STEM |
| **특성 모델** (Petrides) | 감정에 대한 자기효능감, 성격의 하위 차원 | 자기보고 리커트 척도 (평소 행동) | TEIQue (153문항, 단축형 30문항) |
| **혼합·역량 모델** (Bar-On, Goleman) | 정서·사회적 역량, 동기·성격 포함 | 자기보고 + 360도 다면평가 | EQ-i 2.0, ESCI |

- 능력형과 자기보고형은 **상관이 낮습니다** (MSCEIT와 EQ-i r≈.21). 서로 다른 것을 잰다는 뜻입니다.
- 자기보고는 **좋게 보이려는 응답**에 약하고, 능력형은 그 영향을 거의 받지 않습니다.

→ **결정**: 점수는 능력형 문항으로 내고, 자기보고는 점수에 섞지 않고 "내가 보는 나 vs 실제 수행" 비교로만 쓴다.

## 2. 기존 검사를 그대로 쓸 수 있는가

| 검사 | 사용 조건 (조사 시점) | 결정 |
|---|---|---|
| MSCEIT, EQ-i 2.0 | 유료, 자격자만 사용 | 구조만 참고 |
| GECo | 논문 공개, 문항은 매뉴얼 | 구조만 참고 (이론 기반 정답, 영상 감정 인식) |
| STEU·STEM | 연구용 공개 여부 불명확 | 문항 형식만 참고 (상황 판단, 평가 이론 기반 정답) |
| TASIT | 라이선스 필요 | 비꼼·거짓말 이해 과제 구조만 참고 |
| TEIQue-SF | 비상업 연구는 무료, 온라인 사용은 별도 허락 | 사용하지 않음 |
| 표정 사진 DB (FER2013, AffectNet 등) | 대부분 비상업·연구용 | 사용하지 않음 → AI 생성 이미지 + 글 문항 |

→ **모든 문항을 새로 작성**하고, 문항마다 근거 이론(`rationale`)을 적었다.

## 3. 정답을 누가 정하는가

능력형 EQ의 핵심 난제입니다. 감정에는 수학처럼 하나의 정답이 없기 때문입니다.

| 방식 | 내용 | 장단점 |
|---|---|---|
| 다수 합의 채점 | 규준 집단이 가장 많이 고른 답에 점수 | 만들기 쉬우나 "남들과 같은 답"에 점수를 줌 |
| 전문가 채점 | 정서 연구자들의 합의 | 뛰어난 응시자를 놓칠 수 있음 |
| 이론 기반 채점 | 감정 이론(평가 이론 등)으로 정답 결정 | GECo·STEU·MSCEIT 2가 택한 방향 |

- MSCEIT에서 다수 합의 점수와 전문가 점수는 r≈.9 이상으로 매우 일치합니다.

→ **결정**: 이론으로 정답을 정하고, 응답이 쌓이면 관리자 페이지에서 **능력 상위 절반의 다수 선택이 정답과 다른 문항**을 찾아 검토한다.

## 4. 점수 척도

- EQ-i 2.0과 MSCEIT 모두 **평균 100, 표준편차 15** 표준점수를 씁니다.
- 해석 구간 (MSCEIT·EQ-i 참고): 130 이상 매우 우수 · 115~129 우수 · 90~114 보통 · 70~89 개발 필요 · 69 이하 집중 개선 필요.
- 낮은 점수에는 낙인 대신 성장 중심 표현을 쓰고, 개선 방법을 함께 안내하라는 권고를 따랐습니다.

## 5. 측정 영역

사용자와 정한 8개 영역과 근거입니다.

| 영역 | 근거 |
|---|---|
| 감정 인식 | MSCEIT 1영역(얼굴·그림 과제), GECo 감정 인식 |
| 감정 이해 | MSCEIT 3영역(감정 변화·복합 감정 과제), STEU(평가 이론) |
| 감정 활용 | MSCEIT 2영역(사고 촉진·감각 과제). 연구에서 다른 영역과 구분이 약해 **참고용**으로 표시 |
| 감정 조절 | MSCEIT 4영역 일부, STEM, GECo 감정 조절, Gross 정서조절 과정 모형 |
| 대인관계·공감 | MSCEIT 관계 관리, GECo 감정 관리(타인) |
| 관계 갈등 | 사용자 추가. 사회적 갈등(적응·배신·소외·가족·연애)에서 고른 **해결 방식**, Thomas-Kilmann 갈등 대처 유형·관계 회복 연구 참고 |
| 위기 대처 | 사용자 추가. 상황 판단 검사(SJT) + 문항별 시간 압박 |
| 맥락 파악 | 사용자 추가. TASIT(비꼼·거짓말), 화용론(Grice의 함축, 공손성 이론) |

- STEU·STEM 연구에서 하위 점수 구조가 의도대로 나오지 않아 "총점만 쓰라"는 결론이 있었습니다 → **종합 EQ 중심**, 영역 점수는 오차 범위와 함께 보여 준다.

## 6. AI 생성 얼굴 이미지

- AI 생성 표정이 실제 사진만큼 정확히 읽히는지 직접 비교한 연구는 찾지 못했고, 생성기가 특정 감정을 잘 구분해 만들지 못한다는 연구가 있었습니다.
- → 이미지마다 사람 검수를 거치고, 출시 후 관리자 분석으로 계속 확인한다. 이미지가 준비될 때까지 글 문항으로 대체 출제한다 ([08](08_이미지_문항_제작.md)).

## 7. 사용자가 가져온 보고서 2개

| 반영한 것 | 출처 |
|---|---|
| 감정 이해에 '감정 변화'·'복합 감정' 과제 | 보고서 2 (MSCEIT 과제 구성) |
| 감정 인식에 '풍경·추상 이미지' 과제 | 보고서 2 (MSCEIT 그림 과제) |
| 감정 활용을 7번째 영역으로 | 보고서 2 → 사용자 결정 |
| 해석 구간과 성장 중심 표현, 개선 방법 안내 | 보고서 1·2 |
| 자기보고 응답 점검 문항(긍정 인상 척도)과 역문항 | 보고서 1·2 |
| 다수 응답과 정답 비교 | 보고서 2 (합의-전문가 점수 r≈.9 이상) |
| 신뢰도 기준 α ≥ .70 | 보고서 1 |

| 반영하지 않은 것 | 이유 |
|---|---|
| T점수 (평균 50, 표준편차 10) | EQ-i·MSCEIT 모두 100/15. IQ 앱과 같은 척도 유지 |
| 보고서 1의 샘플 문항 20개 | 대부분 자기보고 문장이고, 상황판단 문항은 오답이 뻔함 ("화를 낸다") |
| 선택지마다 효과를 평정 (MSCEIT) | 문항당 시간이 길어짐 → 어려운 단계만 '가장 맞음·가장 아님' 고르기 |
| 360도 다면평가 (ESCI) | 익명 1인 응시 구조와 맞지 않음 |

보고서 1의 사실 오류: GECo 채점을 "전문가 합의"로 적었으나 원 논문은 이론 기반, WLEIS를 "40문항 강제선택"으로 적었으나 16문항 리커트.
