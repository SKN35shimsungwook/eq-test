## 1. 위기 대처: 읽기와 판단 분리

**문제**: 문제와 보기를 합쳐 127~154자를 25~35초 안에 읽고 골라야 해서, 읽기 느린 사람이 판단력과 무관하게 손해를 봤습니다.

**바꾼 것**
- 1단계 **상황 읽기**: 상황만 보여 주고 시간 제한 없음. "보기 열기"를 누르면 2단계로. 읽은 시간은 따로 기록(`read_ms`).
- 2단계 **판단**: 보기가 열리는 순간부터 제한시간. 보기 글자 수(70~82자)와 생각 시간을 봇으로 재서 95%가 들어오도록 25초(쉬움·보통)·30초(어려움 이상).
- 새로고침해도 보기를 이미 열었으면 판단 단계와 남은 시간이 유지됩니다.

| 시나리오 A (초당 8자) | 빠른 전 → 후 | 정밀 전 → 후 |
|---|---|---|
| 문항 시간 초과 | 19.4% → **1.8%** | 23.7% → **2.5%** |
| 1개 이상 시간 초과한 사람 | 35% → 6% | 57% → 12% |
| 읽기 느린 1/4의 문항 시간 초과 | 60.8% → **5.0%** | 64.2% → **7.5%** |
| 위기 대처 점수 ↔ 참 능력 | 0.56 → **0.73** | 0.61 → **0.82** |
| 위기 대처 점수와 읽기 속도의 편상관 | 0.48 → **0.05** | 0.59 → **0.15** |

빨리 읽는 시나리오 B(초당 12자)에서는 시간 초과 0.4%, 편상관 0.00입니다. 이제 위기 대처도 다른 영역과 같은 수준으로 측정됩니다
(수렴 0.73~0.84). 정밀 검사의 편상관 0.15는 보기를 읽는 시간이 아직 판단 시간에 들어 있기 때문입니다.

## 2. 규준: 영역 능력이 서로 다른 사람 기준으로

**문제**: 규준을 만든 봇은 모든 영역 능력이 같았습니다. 영역 능력이 서로 다르면 EQ가 100 쪽으로 몰렸습니다(표준편차 약 10).

**바꾼 것**
- `build_sim_norms.py --rho 0.5`: 영역 능력 = √0.5 × 일반 능력 + √0.5 × 영역 고유 능력. 종합의 참값은 영역 능력 평균을 표준화한 값.
- 부분 점수(3번)도 함께 반영해 규준을 다시 만들었습니다 (모드별 2만 명).
- 실제 응시자 분포로 바꾸는 기준을 **100명 → 300명**으로 (백분위 오차 ±5%p → ±3%p).

| 시나리오 A | 빠른 전 → 후 | 정밀 전 → 후 |
|---|---|---|
| EQ 평균 | 98.9 → 100.1 | 98.9 → 99.7 |
| EQ 표준편차 (목표 15) | 10.5 → **14.9** | 10.0 → **15.0** |
| 130 이상 (기대 2.3%) | 0.4% → **2.1%** | 0.1% → **2.3%** |
| 70 미만 (기대 2.3%) | 0.4% → 2.1% | 0.3% → 2.2% |

새 규준의 90% 범위 적중률은 점수 변환 후 88.9~91.7%이고, 단계별 배율(0.94~1.03)로 90%에 맞춥니다.
참값과의 오차는 빠른 1차 ±6.1점 → 심층까지 ±3.0점, 정밀 1차 ±4.5점 → ±2.5점입니다
(8개 영역의 평균 능력을 맞히는 것이라 예전 '모든 영역 같음' 가정보다 조금 큽니다).

**민감도: 실제 영역 상관을 모른다는 한계**

| 실제 영역 상관 | EQ 표준편차 (빠른 / 정밀) | 130 이상 |
|---|---|---|
| 0.3 | 12.7 / 12.2 | 0.8 / 0.6% |
| **0.5 (가정)** | **14.9 / 15.0** | **2.1 / 2.3%** |
| 1.0 (모든 영역 같음) | 20.2 / 21.4 | 8.0 / 8.0% |

실제 상관이 0.5에서 멀면 분포가 다시 좁아지거나 넓어집니다. 첫 응시자 300명이 모이면 실제 분포로 바뀌어 이 가정은 사라집니다.

## 3. 최선·최악 부분 점수

**바꾼 것**: 최선·최악 문항을 두 단계(① 최선을 맞히나 → ② 최선을 맞혔을 때 최악도 맞히나)로 봅니다.
θ=0에서 둘 다 맞힐 확률은 예전과 같게(45%·25%) 두고, 최선만 맞히면 0.5점으로 추정에 반영합니다.
'맞힌 문항'·문항 판정은 예전처럼 둘 다 맞아야 정답으로 셉니다.

- 최선·최악 응답의 18~19%가 '최선만 맞힘'이라 예전에는 0점으로 버려졌습니다.
- 개선 후 종합 EQ와 참값의 상관: 빠른 0.90 → **0.92**, 정밀 0.94 → **0.96**. 재검사: 0.83 → **0.85**, 0.90 → **0.92**.
  (1번 위기 대처 개선과 함께 나온 효과입니다. 시간 제한이 없는 시나리오 C에서도 정밀 재검사 0.91 → 0.92)
- 심층검사의 문항 선택도 세 단계 모형의 정보량으로 바뀌었습니다.

## 4. 빠른 검사의 영역 표시

영역마다 4문항뿐이면 90% 범위가 ±22점이라 막대그래프가 오해를 부릅니다. 이제 영역 응답이 4개 이하면
영역별 **"강점 후보 / 키울 영역 후보 / –"** 와 범위만 표로 보여 주고, 2·3차 검증을 더 하면 그래프가 나옵니다.

| 빠른 검사 1차 (A) | 결과 |
|---|---|
| 강점 후보가 표시된 사람 | 46% |
| 표시된 강점 후보가 실제로 본인 평균보다 높음 | **92%** |
| 키울 영역 후보가 실제로 본인 평균보다 낮음 | **94%** |

## 5. 유형 이름: 약한 경향도 보여 주기

뚜렷한 축(z ≥ 2.3)이 없어도 z ≥ 1.96인 축이 있으면 **"표현형 경향"** 처럼 이름을 붙이고 "확신도 약함" 표시와
"2·3차를 더 하면 또렷해지거나 사라집니다" 안내를 붙입니다.

| 정밀 1차 | 전 | 후 |
|---|---|---|
| 균형형·상황맞춤형 (세 시점 봇) | 56% | **43%** |
| 서로 다른 이름 수 | 26개 | 34개 |
| 성향이 강한 1/3이 축 이름을 받음 | 67% | **78%** |
| 이름의 축 방향이 참 성향과 맞음 (유형 봇, 강한 / 약한 성향) | 97.7 / 95.5% | 96.7 / 94.3% |
| **버릇 없는 봇이 이름을 받음 (유형 봇)** | 3.7% | **10.6%** (대부분 '경향 · 약함') |
| 다시 했을 때 이름 완전 같음 (세 시점 봇) | 52% | 42% |

**대가**: 이름을 받는 사람이 늘어난 만큼 버릇이 없는데 '약한 경향' 이름을 받는 사람도 3.7% → 10.6%로 늘었고,
이름이 세분화되어 다시 했을 때 같은 이름일 확률이 낮아졌습니다. 그래서 약한 경향에는 반드시 확신도를 함께 보여 줍니다.

## 7. 경계 근처 안내

종합 점수가 수준 경계(70·90·115·130)에서 표준오차의 0.67배 안쪽이면(건너편일 확률 25% 이상)
"'보통'·'우수' 두 수준의 경계 근처라 다시 검사하면 수준 이름이 바뀔 수 있습니다"라고 안내합니다.

| 시나리오 A | 빠른 | 정밀 |
|---|---|---|
| 안내를 받은 사람 | 39% | 28% |
| 다시 했을 때 수준 이름이 바뀐 사람 | 29% | 22% |
| 그중 1차에서 미리 안내를 받았던 사람 | 58% | 49% |

처음에는 "90% 범위가 경계를 걸치면 안내"로 했더니 67~83%가 안내를 받아(바뀐 사람의 90~94%를 잡지만) 대부분에게 의미 없는 문구가 되었습니다.
지금 기준은 안내를 아껴 쓰는 대신 바뀌는 사람의 절반 정도를 미리 알려 줍니다.
다시 할 때는 두 번째 검사의 오차도 더해지므로 한 번의 검사만으로 모두 미리 알 수는 없습니다.

**참고**: 수준 이름이 바뀌는 비율(빠른 20 → 29%, 정밀 14 → 22%)은 개선 전보다 늘었습니다. EQ가 100 근처에 몰려 있다가(대부분 '보통')
제대로 퍼지면서 경계 근처에 있는 사람이 늘었기 때문입니다. 다시 했을 때 점수 차이 중앙값을 표준편차로 나누면 개선 전후가 비슷합니다 (빠른 0.39 → 0.37, 정밀 0.28 → 0.27).

## 8. 연구 과제 준비

시뮬레이션으로 대신할 수 없는 과제는 도구와 계획을 준비했습니다.

**전문가 정답 검토** (`scripts/expert_review.py`)
1. `python scripts/expert_review.py export` → `review/expert_review.csv` (315문항: 상황·보기와 유형·현재 정답·해설 + 빈 검토 칸)
2. 검토자 3명 이상이 각자 '정답 동의(Y/N)', '내가 고른 정답', '단서 명확성(1~5)', '의견'을 채움
3. `python scripts/expert_review.py summarize 파일들.csv` → 문항별 동의율·다른 정답 제안·명확성 평균, **동의율 70% 미만 또는 명확성 3 미만은 '다시 보기'**
4. 가짜 검토자 3명으로 확인: 일부러 반대한 문항을 '다시 보기'로 찾아냄 (동의 33% · 다른 정답 B×2)

## 10. 남은 한계

- 모든 수치는 봇 모형 기준입니다. 특히 **영역 상관 0.5**와 **읽기 속도 초당 8자**는 가정이고, 결과가 이 가정에 민감합니다(2절 민감도).
- 6번에서 고친 40문항의 정답은 제가 쓴 것이라, 전문가 검토 전까지는 다른 문항과 같은 '초안' 상태입니다.
- 이미지 20장, 실제 응답 기반 보정, 타당도 연구는 그대로 남아 있습니다.
